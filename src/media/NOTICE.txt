Road Desk media plane (src/media) uses a private TLS mux protocol and optional
self-developed Mirror capture. It does not link LibVNC or other GPL media libraries.

miniz (third_party/miniz) is MIT-licensed zlib-compatible compression used for
dirty-rect payloads. See third_party/miniz/LICENSE.

Historical LibVNC MVP sources (libvnc_*.cpp, win_input.*) may remain in-tree for
reference but are not built. Rollback: git tag libvnc-mvp-verified-2026-08-01.
