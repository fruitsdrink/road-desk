# MVP 可用 GPL 媒体组件，正式交付前换合规底座

Status: accepted

媒体面 MVP 为加速验证可临时使用 GPL 等 copyleft 的 VNC 组件做内部样机与联调。本产品若装到收费站或对外交付，不得在未审许可的情况下把此类组件打进正式安装包。正式对外发布前必须换成合规底座（商业授权、宽松许可实现，或经探针后的自研媒体面适配器）。ADR-0001 的适配器边界正是为这次替换服务。

## Considered Options

- **接受 GPL 并随产品 copyleft 发布** — 未采纳；交付形态与合规约束未按此假设设计
- **从第一天只用宽松/商业授权底座** — 更干净，但会拖慢 MVP 对 Win7 共享控制台的验证
- **MVP 内部可用 GPL，交付前替换** — 采纳；用时间换清爽的验证路径，并用适配器控制替换成本

## Consequences

- 内部构建与正式交付构建的媒体面依赖可以不同，但操作端/被控端代理对媒体面的会话 API 必须稳定
- 选型或引入任何 VNC/编解码依赖时，须先记录许可证；探针结论需包含「合规替换」工作量，而非仅技术可行性
- 「开源」不得被默认等同于「可任意商用」
